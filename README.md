# Project Py — Виджет банковских операций

Виджет для отображения и обработки транзакций клиента в личном кабинете банка. Реализует фильтрацию, генерацию тестовых данных, маскирование чувствительных данных и базовую обработку операций.

## Функционал

- **Фильтрация транзакций**: по валюте (`filter_by_currency`), статусу, дате.
- **Поиск по описанию**: с использованием регулярных выражений (regex).
- **Подсчёт категорий**: агрегация операций по категориям через `Counter`.
- **Генераторы тестовых данных**: номера карт, описания транзакций, наборы операций.
- **Маскирование данных**: модуль `masks` скрывает номера счетов/карт.
- **Логирование**: отдельные логгеры для модулей `masks` и `utils` с единым форматом (метка времени, название модуля, уровень серьёзности, сообщение).
- **Тестирование**: юнит‑тесты на `pytest`, покрытие кода ≥80%, типизация `mypy`, линтинг `flake8`.
- Поиск операций по описанию с использованием регулярных выражений (re).
- Подсчёт количества операций по категориям (на основе поля description).
- Улучшенная сортировка и фильтрация транзакций, включая обработку ошибок.

## Технологии

- Язык программирования: Python 3.14
- Веб‑фреймворк: Flask (лёгковесный сервер для API)
- База данных: SQLite (для демонстрации; в продакшене — PostgreSQL/Oracle)
- Форматы данных: JSON (обмен между бэкендом и фронтендом)
- Управление зависимостями: Poetry
- Контроль версий: Git
